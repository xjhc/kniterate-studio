# 3/28 cashmere stitch sizes 6 and 5

Use this 322-pass `command.kc` for the two-setting trial. It knits one 48-stitch rectangle with one waste start and two panels of the same reversible paisley. The solid contrast divider knits with the existing colours, reversing colour on the other face. The first fabric off the machine is stitch size 6.

## Thread and run

| Feeder | Yarn |
| --- | --- |
| C1 | Usual smooth draw thread |
| C3 | One end of 3/28 cashmere in colour A, the cast-on colour |
| C4 | One end of 3/28 cashmere in colour B, the contrast divider on the front |
| C6 | Usual waste yarn |

Start on an empty bed with the feeders at home on the left. Body speed is 150 and roller is 400 across the two panels. The first body row uses speed 100 and roller 100. Watch C3 entering at pass 83, C4 at pass 89, and the cast-on and body entry at passes 108–112. If a yarn breaks or loops drop, stop and record the pass and feeder.

| From cast-on upward | Body rows | Body knitting passes | Gauge marks at rows |
| --- | --- | --- | --- |
| Stitch size 6 | 1–30 | 111–199 | 5 and 27 |
| Contrast divider | 31–32 | 201–205 | |
| Stitch size 5 | 33–62 | 207–295 | 37 and 59 |

Body pass ranges include carriage repositioning between knitting passes. Each section repeats the same chart and uses the same joined side edges.

## Measure and choose

Pull the C1 draw thread. Secure both faces on loose lifelines before removing the top waste. Compare the panels after washing or finishing per the yarn label and letting them dry flat.

Measure between the cross centres in each section. Average the two horizontal spans and the two vertical spans, in cm. Each window spans 38 stitch intervals and 22 row intervals. Divide 380 by the width and 220 by the height to estimate stitches and rows per 10 cm. The short windows are for comparison. Confirm the selected setting on a larger window before using its gauge for the full scarf.

For a good candidate, both faces should knit without repeated breaks or missed loops, the edges should stay joined, and the washed fabric should have the drape and definition you want. If the fabric is too open or unreliable at both settings, make a separate trial if moving to 6/28.

Software validation verified the carrier, bed, stitch size, speed, and roller on each of the 62 body rows. The independent machine check and loop replay passed. Physical yarn behavior is still to be tested.
